## What is IndexToast?

IndexToast is a bulk URL indexing service built for anyone who manages links at scale. Whether you're a PR agency handling hundreds of client links, a publisher pushing out daily content, or an SEO professional managing large link-building campaigns — IndexToast helps you get pages discovered and indexed by Google quickly.

## Key Features

### Bulk URL Submission
Submit URLs in bulk — paste them directly, upload a CSV, or import from a sitemap. Each batch supports up to **1,000 URLs**, and a single portfolio can hold up to **1.5 million URLs**.

### Two Speed Levels
- **Standard** — Typical turnaround of 1–72 hours. Great for everyday indexing.
- **Priority (Boost)** — Average turnaround under 15 minutes. For time-sensitive pages.

### Real-Time Status Tracking
Every URL moves through clear stages: **Ready → Processing → Visible**. Monitor progress and export results from one unified dashboard.

### Index Checker
Quickly verify whether any URL is already indexed by Google — no guesswork needed.

### Connected Websites
Verify domains you own to unlock sitemap discovery, automation, and ongoing indexing management.

### Integrations & Access

| Integration | Description |
|---|---|
| **WordPress Plugin** | Automate indexing directly from your WordPress dashboard |
| **Chrome Extension** | Capture pages, collect URL lists, and check indexing status from your browser |
| **MCP Access** | Scoped, revocable access for AI assistants with confirmation gates |
| **Business API** | Programmatic access for large-scale and enterprise workflows |
